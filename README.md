# Pancreolana (Pancreatitis ML) — Modernized Fork

Мобильная клиническая система оценки риска осложнений и прогнозирования форм острого панкреатита (МКБ-10: K85) на основе автономного ML-инференса.

Данный форк представляет собой глубокую архитектурную модернизацию исходного приложения: монолитная кодовая база разделена на независимое ядро и Android-клиент, эвристические текстовые алгоритмы заменены на нативный рантайм ONNX Runtime 1.31.0, внедрена дизайн-система Material 3 и реализовано строгое соответствие стандартам РФ (МКБ-10, система СИ, 152-ФЗ).

---

## Ключевые изменения форка

### 1. Архитектурная декомпозиция (`:core` + `:app`)
* **Модуль ядра `:core` (Java 17):** полностью очищен от зависимостей Android SDK (`android.*`). Содержит доменные сущности, SPI-контракты (`DatabaseDriver`, `StoragePathProvider`), парсер динамического манифеста и инференс-движок. Может переиспользоваться в десктопных и серверных сервисах.
* **Модуль клиента `:app` (Android):** отвечает за пользовательский интерфейс, аппаратную криптографию Android Keystore, управление локальной БД SQLite и жизненный цикл ассетов моделей.

### 2. Промышленный ML-пайплайн (ONNX Runtime 1.31.0)
* **Поддержка 5 валидированных моделей:** CatBoost, XGBoost, LightGBM, Random Forest, Logistic Regression (формат `.onnx`, `opset 22`).
* **Динамическая схема признаков:** 42 клинико-лабораторных показателя нормализуются через Z-score scaling на основе метаданных `model_manifest.json`.
* **Отказоустойчивость:** автоматическая подстановка эталонных значений по умолчанию при пропусках в анкете и физиологическое ограничение значений диапазоном `[min, max]`.
* **Криптографический контроль:** проверка целостности файлов моделей по алгоритму SHA-256 перед загрузкой сессии с защитой от подмены.

### 3. Медицинские стандарты и требования регуляторов
* **МКБ-10 (K85):** каноническая классификация форм (отёчная vs. некротическая).
* **Международная система единиц (СИ):** все 42 показателя приведены к нормативным размерностям ($10^9$/л, ммоль/л, Ед/л, мг/л и др.).
* **Формализованный протокол для МИС / ЕМИАС:** генерация структурированного протокола обследования с экспортом в буфер обмена отдельным действием.
* **Нормативный медицинский дисклеймер:** юридическое уведомление о вспомогательном характере математического моделирования.
* **152-ФЗ:** защита локальных данных через `EncryptedSharedPreferences` / Android Keystore (AES-256-GCM), псевдонимизация записей пациентов и хеширование паролей (PBKDF2WithHmacSHA256, 100 000 итераций).

### 4. Дизайн-система Material 3
* Адаптивная светлая и тёмная темы по стандартам доступности (WCAG 2.1 AA / ГОСТ Р 52872-2019).
* Семантическая цветовая индикация клинического риска (зеленый / красный контейнеры).
* Горизонтальные индикаторы распределения вероятностей и селектор модели «на лету».

### 5. Инженерная диагностика и тестирование
* **Временный мост авторизации (`AuthTestBridge`):** возможность автономного входа без внешнего сервера (`USE_TEST_AUTH = true`).
* **Скрытый экран отладки (`DebugDiagnosticsActivity`):** вызывается 7 быстрыми нажатиями на номер версии в профиле врача. Включает бенчмарк моделей, замер задержек инференса, инспектор тензоров и тумблеры выборочного отключения нормализации/хешей.
* **Top Banner:** 5-секундный всплывающий баннер при старте приложения при наличии активных отладочных переопределений.

## Структура проекта

```text
Pancreatitis/
├── core/                               # Кроссплатформенное ядро (Java 17)
│   └── src/main/java/com/pancreatitis/core/
│       ├── database/                   # SPI-абстракции доступа к данным
│       ├── ml/                         # OnnxInferenceEngine, FeatureNormalizer, ChecksumVerifier
│       ├── model/                      # Доменные сущности (Patient, Questionnaire)
│       ├── model/ml/                   # Схемы признаков, манифест и метаданные моделей
│       └── storage/                    # SPI файловой системы
├── app/                                # Мобильный клиент (Android)
│   ├── src/main/assets/models/         # Веса моделей (.onnx) и model_manifest.json
│   └── src/main/java/com/pancreatitis/
│       ├── infrastructure/             # Реализации SPI, AuthTestBridge, ClinicalTerminology
│       ├── modules/prediction/         # Фасад PredictionModule
│       └── ui/                         # Material 3 экраны, диалоги и DebugDiagnosticsActivity
└── gradle/libs.versions.toml           # Каталог версий библиотек (Version Catalog)
```

## Сборка и запуск

### Требования
* JDK 17
* Android SDK Platform 34 / Build Tools 34.0.0
* Поддерживаемые архитектуры: `arm64-v8a`, `armeabi-v7a`, `x86_64`

### Команды Gradle

```bash
# Запуск unit-тестов ядра и приложения
./gradlew test

# Сборка установочного отладочного пакета
./gradlew :app:assembleDebug
```

Сгенерированный файл: `app/build/outputs/apk/debug/app-debug.apk`

---

## Установка на устройство

Через Android Debug Bridge (ADB):

```bash
adb devices
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
